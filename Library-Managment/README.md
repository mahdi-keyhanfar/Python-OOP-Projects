# 📚 Python Library Management System

**An object-oriented Python project focused on inheritance, abstraction, encapsulation, and class design.**

🇮🇷 [**فارسی**](README.fa.md) · 🇬🇧 **English**

---

## 📖 Overview

A Python project designed to demonstrate Object-Oriented Programming (OOP) principles through the implementation of a library item management system.

The project models different types of publications, including books, magazines, and research journals, using a structured class hierarchy.

It focuses on designing reusable classes, managing object attributes, implementing validation logic, and defining relationships between parent and child classes.

---

## 🎯 Key Features

- Abstract base class implementation using Python's `abc` module.
- Inheritance and class hierarchy design.
- Encapsulation using properties, getters, and setters.
- Attribute validation and data management.
- Class methods, static methods, and instance methods.
- Custom operator overloading using Dunder Methods.
- Object identification and item counting.
- Publication information management.
- Reading time calculation.
- Research journal metrics and editorial board management.

---

## 🏗️ Class Architecture

The project follows this inheritance structure:

```text
Item (Abstract Base Class)
│
├── Book
│
└── Magazine
    │
    └── ResearchJournal
```

### Main Classes

| Class | Description |
|---|---|
| `Item` | Abstract base class containing shared publication attributes and methods. |
| `Book` | Represents books and manages author, edition, and digital/audio formats. |
| `Magazine` | Represents magazines and handles publication periods, editors, and reading time. |
| `ResearchJournal` | Represents academic journals and manages research-related information and metrics. |
