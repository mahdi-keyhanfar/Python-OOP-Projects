## 🇬🇧 English

### Overview

A collection of Python applications and practical projects developed with a focus on Object-Oriented Programming (OOP), software design, and structured application development.

This repository demonstrates the practical application of Python OOP concepts through projects that focus on building organized, reusable, and maintainable software.

### 🎯 Key Objectives

- Apply Object-Oriented Programming principles in practical applications.
- Design and implement classes, objects, and their relationships.
- Develop modular and maintainable code structures.
- Implement application logic and data management.
- Improve problem-solving and software development skills.
- Build a foundation for developing larger Python applications.

### 🛠️ Technical Skills

- **Language:** Python
- **Programming Paradigm:** Object-Oriented Programming
- **Core Concepts:** Encapsulation, Inheritance, Polymorphism, Abstraction
- **Development:** Modular Programming, Exception Handling, Code Reusability
- **Software Design:** Class Design, Object Relationships, Application Structure

### 📂 Repository Structure

Projects are organized into separate directories, with each project focusing on specific programming concepts and implementation challenges.

### 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/mahdi-keyhanfar/Python-OOP-Projects.git
```

Navigate to the repository:

```bash
cd Python-OOP-Projects
```

Explore the project directories and follow the instructions provided in each project's documentation.
