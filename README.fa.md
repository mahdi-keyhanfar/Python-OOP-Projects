# 🐍 پروژه‌های برنامه‌نویسی شی‌گرا با پایتون

**مجموعه‌ای از پروژه‌های عملی پایتون با تمرکز بر برنامه‌نویسی شی‌گرا و توسعه نرم‌افزار**

🇮🇷 **فارسی** · 🇬🇧 [English](README.md)

---

## 📖 معرفی

این مخزن شامل مجموعه‌ای از برنامه‌ها و پروژه‌های عملی توسعه‌یافته با زبان Python است که بر برنامه‌نویسی شی‌گرا (OOP)، طراحی نرم‌افزار و توسعه ساختاریافته برنامه‌ها تمرکز دارند.

هدف این مجموعه، نمایش کاربرد عملی مفاهیم برنامه‌نویسی شی‌گرا از طریق توسعه نرم‌افزارهایی با ساختار منظم، کدهای قابل استفاده مجدد و قابلیت نگهداری مناسب است.

---

## 🎯 اهداف اصلی

- پیاده‌سازی اصول برنامه‌نویسی شی‌گرا در پروژه‌های عملی.
- طراحی و توسعه کلاس‌ها، اشیا و ارتباط میان آن‌ها.
- ایجاد ساختارهای ماژولار و قابل نگهداری.
- پیاده‌سازی منطق برنامه و مدیریت داده‌ها.
- تقویت مهارت حل مسئله و توسعه نرم‌افزار.
- ایجاد پایه‌ای مناسب برای توسعه برنامه‌های بزرگ‌تر با پایتون.

## 🚀 نحوه دریافت و اجرا

ابتدا مخزن را دریافت کنید:

```bash
git clone https://github.com/mahdi-keyhanfar/Python-OOP-Projects.git
```

وارد پوشه مخزن شوید:

```bash
cd Python-OOP-Projects
```

سپس پوشه پروژه موردنظر را بررسی کرده و مطابق مستندات آن، برنامه را اجرا کنید.
