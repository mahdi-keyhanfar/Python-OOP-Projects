نکات مهم پیاده‌سازی

  • کلاس Item باید abstract base class باشد - از abc module استفاده کنید
  • متد abstract full_info باید در همه کلاس‌های فرزند پیاده‌سازی شود
  • Dunder methods باید مناسب با نوع کلاس تعریف شوند
  • Class attributes برای شمارش تعداد اشیا استفاده می‌شوند
  • Property decorators برای getter و setter استفاده کنید
  • متدهای مجاز Dunder: __str__, __len__, __sub__, __add__, __del__
  • تغییرات اعمال شده:
    • متد is_old از کلاس Item حذف شد
    • توضیح پارامتر read_speed در متد calculate_reading_time اضافه شد
