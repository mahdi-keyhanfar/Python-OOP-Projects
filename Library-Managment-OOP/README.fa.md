# 📚 سیستم مدیریت اقلام کتابخانه با پایتون

**پروژه‌ای شی‌گرا با تمرکز بر وراثت، انتزاع، کپسوله‌سازی و طراحی کلاس‌ها**

🇮🇷 **فارسی** · 🇬🇧 [English](README.md)

---

## 📖 معرفی

این پروژه با زبان Python و با هدف پیاده‌سازی عملی مفاهیم برنامه‌نویسی شی‌گرا (OOP) در قالب یک سیستم مدیریت اقلام کتابخانه توسعه داده شده است.

در این پروژه انواع مختلف انتشارات از جمله کتاب‌ها، مجلات و ژورنال‌های پژوهشی با استفاده از یک ساختار سلسله‌مراتبی از کلاس‌ها مدل‌سازی شده‌اند.

تمرکز اصلی پروژه بر طراحی کلاس‌های قابل استفاده مجدد، مدیریت ویژگی‌های اشیا، اعتبارسنجی داده‌ها و ایجاد ارتباط میان کلاس‌های والد و فرزند است.

---

## 🎯 قابلیت‌های اصلی

- پیاده‌سازی کلاس انتزاعی با استفاده از ماژول `abc`.
- طراحی ساختار وراثت و سلسله‌مراتب کلاس‌ها.
- پیاده‌سازی کپسوله‌سازی با استفاده از Property، Getter و Setter.
- اعتبارسنجی ویژگی‌ها و مدیریت داده‌ها.
- استفاده از متدهای نمونه، کلاسی و استاتیک.
- بازنویسی عملگرها با استفاده از Dunder Methods.
- تولید شناسه و شمارش اشیا.
- مدیریت اطلاعات انواع انتشارات.
- محاسبه زمان مطالعه.
- مدیریت اطلاعات و شاخص‌های ژورنال‌های پژوهشی.

## 🏗️ ساختار کلاس‌ها

ساختار وراثت پروژه به شکل زیر طراحی شده است:

```text
Item (Abstract Base Class)
│
├── Book
│
└── Magazine
    │
    └── ResearchJournal
```

### معرفی کلاس‌ها

| کلاس | توضیحات |
|---|---|
| `Item` | کلاس پایه انتزاعی شامل ویژگی‌ها و متدهای مشترک انتشارات |
| `Book` | مدیریت اطلاعات کتاب، نویسنده، ویرایش و نسخه‌های دیجیتال و صوتی |
| `Magazine` | مدیریت مجلات، تناوب انتشار، سردبیر و زمان مطالعه |
| `ResearchJournal` | مدیریت اطلاعات ژورنال‌های علمی، شاخص‌های پژوهشی و هیئت تحریریه |
